LOLA Pet Shop

Descripción del proyecto
LOLA Pet Shop es un sitio web dedicado a la venta de productos para mascotas. 
Buscamos una forma de navegación sencia y visualmente atractiva donde los usuarios puedan conocer 
los productos disponibles, separados por categorías y realizar consultas. Usamos un diseño moderno 
y colorido con colores coral, amarillo y turquesa. El nombre de la tienda está inspirado en la 
mascota de uno de los integrantes del grupo y seleccionamos los productos que más nos gustaron, 
realizando también una sección de productos destacados. 

El sitio está compuesto de tres páginas:
- Index: se muestra la tienda, sus categorías y una sección de productos destacados.
- Productos: muestra el catálogo organizado por categorías y una guía de talles para la elección de las prendas
- Contacto: contiene los datos de contacto de la tienda y un formulario para que puedan enviar consultas.
En las tres páginas tenemos la opción de navegación entre ellas, efectos de transición al interactuar con botones,
categorías y los productos. También cuenta con un diseño responsive y tiene en el footer los enlaces a las redes sociales.

Se usaron selectores, clases e identificadores para organizar los estilos y herramientas como flexbox y grid para poder distribuir
los distintos elementos según el ancho de la pantalla.

Instrucciones para visualizar el proyecto
1. Descargar el repositorio
2. Abrir la carpeta del proyecto
3. Ejecutar el archivo index.html en un navegador web
4. Utilizar el menú de navegación para ir entre las distintas secciones
